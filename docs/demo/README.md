# Video demo

Đặt file video vào thư mục này với tên **`demo.mp4`** (định dạng `.mp4`, dài dưới 5 phút, dung lượng dưới 100 MB).

Nội dung gợi ý:
1. Chơi trực tiếp một đoạn (nhặt đom đóm, thắp đèn, châm dầu, tỏa sáng).
2. Chạy `npm test` và cho thấy 108 test đạt.
3. Chạy `npm run bench` và cho thấy kết quả `bench.json`.
4. Lướt qua `soak.json`, README, harness AI (AGENTS.md, `.claude/`) và lịch sử git.
